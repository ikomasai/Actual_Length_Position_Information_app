# 位置情報オンデマンド送信アプリ - 実装概要

## 概要

ERPシステムからの呼び出しに応じてユーザーの位置情報を取得し、Supabaseに保存するiOS対応アプリ。
既存のSupabase認証システム（auth.users, user_profiles, user_roles, roles）を活用。

## 認証システム

### ログイン
- ERPシステムと同じSupabaseアカウントでログイン
- メールアドレス + パスワード認証
- ログイン後、位置情報サービス画面へ遷移

### ユーザー管理
- `auth.users` テーブルを使用（既存のERPユーザー）
- user_id は UUID（auth.users.id）
- ユーザー情報は `user_profiles` テーブルに保存済み

## データベーステーブル

### locations（新規作成）
位置情報を保存するテーブル

```sql
CREATE TABLE locations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id),
  latitude DOUBLE PRECISION NOT NULL,
  longitude DOUBLE PRECISION NOT NULL,
  altitude DOUBLE PRECISION,
  accuracy DOUBLE PRECISION,
  speed DOUBLE PRECISION,
  heading DOUBLE PRECISION,
  timestamp TIMESTAMPTZ NOT NULL,
  created_at TIMESTAMPTZ DEFAULT now(),
  request_id UUID
);
```

### location_requests（新規作成）
ERPからの位置情報取得リクエストを管理

```sql
CREATE TABLE location_requests (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id),
  requested_at TIMESTAMPTZ DEFAULT now(),
  completed BOOLEAN DEFAULT false,
  completed_at TIMESTAMPTZ
);
```

## 動作フロー

### 1. アプリ側
1. ユーザーがログイン（ERPと同じアカウント）
2. 「サービス開始」ボタンをタップ
3. Supabase Realtimeで `location_requests` テーブルを監視開始
4. 自分宛のリクエスト（user_id一致）をリアルタイム受信
5. リクエスト受信時、位置情報を取得
6. `locations` テーブルに位置情報を保存
7. `location_requests` の completed フラグを true に更新

### 2. ERP側（実長タブ）
1. 「現在位置を取得」ボタンをクリック
2. 対象ユーザーの user_id で `location_requests` テーブルに INSERT
3. アプリ側からの応答を待機（completed = true になるまで）
4. `locations` テーブルから最新の位置情報を取得（request_id で絞り込み）
5. マップに位置情報を表示

## ERPシステム側の実装

### 位置情報取得リクエスト送信

```javascript
// 実長タブのボタンクリック時
const requestLocation = async (userId) => {
  const { data, error } = await supabase
    .from('location_requests')
    .insert([
      {
        user_id: userId,
      }
    ])
    .select()
    .single();

  if (error) {
    console.error('リクエスト送信エラー:', error);
    return null;
  }

  return data.id; // request_id
};
```

### 位置情報取得

```javascript
// リクエスト送信後、完了を待つ
const waitForLocation = async (requestId, timeout = 30000) => {
  const startTime = Date.now();

  while (Date.now() - startTime < timeout) {
    const { data: request } = await supabase
      .from('location_requests')
      .select('completed')
      .eq('id', requestId)
      .single();

    if (request?.completed) {
      const { data: location } = await supabase
        .from('locations')
        .select('*')
        .eq('request_id', requestId)
        .single();

      return location;
    }

    await new Promise(resolve => setTimeout(resolve, 1000));
  }

  throw new Error('タイムアウト');
};
```

## セキュリティ

### RLSポリシー
- **locations**
  - INSERT: 自分の位置情報のみ登録可能
  - SELECT: 全認証ユーザーが閲覧可能（ERP用）

- **location_requests**
  - SELECT: 自分宛のリクエストのみ閲覧可能
  - INSERT: 全認証ユーザーが登録可能（ERP用）
  - UPDATE: 自分宛のリクエストのみ更新可能

### 権限
- iOS位置情報権限（前景・背景）が必要
- Supabase認証が必要（ERPアカウント）

## トラブルシューティング

### リクエストが受信されない
1. Realtimeが有効化されているか確認
2. user_idが正しいか確認
3. アプリがサービス開始状態か確認

### 位置情報が取得できない
1. iOS位置情報権限が許可されているか確認
2. GPSが有効か確認
3. ネットワーク接続を確認

### ログインできない
1. .envファイルのSupabase設定を確認
2. ERPアカウントのメールアドレス・パスワードを確認
